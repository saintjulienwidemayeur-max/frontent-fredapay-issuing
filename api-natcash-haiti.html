Accepter Natcash avec une API REST

L'API de paiement Freda Pay Issuing vous permet d'accepter Natcash en Haïti depuis votre site, votre application ou votre boutique en ligne. Vous créez un paiement avec method: "natcash", l'API renvoie une adresse checkout_url, vous y redirigez le client, puis vous recevez la confirmation signée sur votre serveur.

Un seul appel

POST /v1/payments avec le montant en HTG, la méthode et votre référence de commande.

Confirmation signée

Le webhook payment.succeeded est signé (HMAC-SHA256). Vous pouvez aussi lire le statut avec GET /v1/payments/:id.

Envoyer de l'argent

Versez de l'argent vers un numéro Natcash avec POST /v1/payouts : remboursements, livreurs, employés, partenaires.

Exemple d'intégration Natcash

Avec le SDK Node.js :

const { FredaPay } = require("@fredapay/issuing");
const freda = new FredaPay("sk_test_VOTRE_CLE");

const payment = await freda.payments.create({
  amount: 1500,
  method: "natcash",
  reference: "CMD-4821"
});

// Redirigez votre client vers payment.checkout_url
// Puis payment.succeeded arrive sur votre webhook signé

Sans SDK, n'importe quel langage fonctionne avec l'API REST :

curl -X POST https://api.fredapay.com/v1/payments \
  -H "Authorization: Bearer sk_test_VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"amount":1500,"method":"natcash","reference":"CMD-4822"}'

Le client paie en gourdes (HTG). Le montant minimum d'un paiement Natcash est de 20 HTG. Le même appel accepte aussi MonCash en changeant la valeur de method.

Comment commencer

  1. Créez un compte et confirmez votre e-mail.
  2. Créez une clé de test sk_test_... dans le tableau de bord, section Clés API.
  3. Faites un premier paiement en mode test, sans argent réel.
  4. Enregistrez votre URL de webhook pour recevoir les confirmations.
  5. Passez en production avec une clé sk_live_... : les mêmes appels fonctionnent.

Vous n'écrivez pas de code ? Utilisez un lien de paiement, le bouton de paiement à copier-coller, ou le plugin WordPress et WooCommerce.

Questions fréquentes

Comment tester l'API Natcash sans argent réel ?

Chaque compte dispose d'un mode test avec des clés sk_test_.... Vous créez des paiements de test et vérifiez votre intégration avant de passer en production.

Comment savoir qu'un paiement Natcash a réussi ?

Enregistrez une URL de webhook : vous recevez un événement signé payment.succeeded. Vérifiez toujours la signature avant de livrer une commande. Vous pouvez aussi interroger l'API avec l'identifiant du paiement.

Puis-je envoyer de l'argent vers Natcash ?

Oui, avec l'API de retrait (POST /v1/payouts), depuis votre solde Gateway. Le statut se suit par webhook (payout.succeeded, payout.failed).

Quels langages puis-je utiliser avec l'API Natcash ?

L'API est une API REST en JSON, utilisable avec tout langage. Nous fournissons des SDK Node.js et PHP, et des plugins WordPress, WooCommerce et Wix.
