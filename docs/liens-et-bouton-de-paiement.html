Lien et bouton de paiement : encaisser sans écrire de code

Deux façons d'accepter des paiements sans développeur : un lien à envoyer par message, et un bouton à copier-coller dans votre site.

Liens de paiement, sans une ligne de code

Pas de site ou pas de développeur ? Créez un lien depuis le tableau de bord et envoyez-le par WhatsApp, SMS, e-mail ou sur vos réseaux sociaux.

  1. Ouvrez « Liens de paiement »dans votre tableau de bord.
  2. Indiquez un montant, ou laissez videSans montant, votre client saisit lui-même la somme : pratique pour les dons ou les factures variables.
  3. Partagez le lienVotre client choisit MonCash ou Natcash et paie. L'argent arrive sur votre solde Gateway.

Bouton de paiement pour n'importe quel site

Collez deux lignes dans votre site pour afficher un bouton « Payer avec Freda Pay Issuing ». Il fonctionne sur Wix, Squarespace, Webflow, Shopify, Blogger ou une simple page HTML.

Le bouton utilise un lien de paiement : il ne contient aucune clé secrète et peut donc être placé sans risque dans une page publique.

  1. Créez un lien de paiement et copiez son identifiant (lnk_…).
  2. Ajoutez un bloc « HTML personnalisé » ou « Embed » dans votre éditeur de site.
  3. Collez le code ci-contre en remplaçant lnk_VOTRE_LIEN.
Code à coller
<div data-freda-link="lnk_VOTRE_LIEN"></div>
<script src="https://issuing.fredapay.com/freda-button.js" async></script>

Options : data-label="Faire un don" change le texte du bouton, data-theme="light" affiche une version claire.
