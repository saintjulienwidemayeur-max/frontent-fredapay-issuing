API de paiement : acceptez les cartes Visa et Mastercard, MonCash et Natcash

Intégrez les paiements par carte (Visa, Mastercard, Amazon Pay, Cash App, Link), MonCash et Natcash à votre site ou application avec une seule API REST. Créez un paiement, redirigez le client, recevez la confirmation signée. Testez gratuitement avant la production.

Une seule API pour MonCash et Natcash

Avec l'API de paiement Freda Pay, vous acceptez les paiements MonCash et Natcash sur votre site, votre application ou votre boutique en ligne, avec le même appel. Le paramètre method choisit le moyen de paiement : moncash, natcash, moncash_ussd (le client valide depuis son téléphone) ou all (le client choisit).

Un appel, un lien de paiement

Vous créez un paiement, l'API renvoie une adresse checkout_url vers laquelle vous redirigez votre client.

Confirmation fiable

Recevez un webhook signé payment.succeeded sur votre serveur, ou vérifiez le statut avec GET /v1/payments/:id.

Envoyer de l'argent

Versez de l'argent vers un numéro MonCash ou Natcash avec POST /v1/payouts : remboursements, paiements de livreurs, d'employés ou de partenaires.

Accepter un paiement MonCash en quelques lignes

Exemple avec le SDK Node.js. Le même appel accepte Natcash en remplaçant la valeur de method.

const { FredaPay } = require("@fredapay/issuing");
const freda = new FredaPay("sk_test_VOTRE_CLE");

const payment = await freda.payments.create({
  amount: 1500,
  method: "moncash",        // ou "natcash", "moncash_ussd", "all"
  reference: "CMD-4821"
});

// Redirigez votre client vers payment.checkout_url
// Puis payment.succeeded arrive sur votre webhook signé

Sans SDK, l'API REST fonctionne avec n'importe quel langage :

curl -X POST https://api.fredapay.com/v1/payments \
  -H "Authorization: Bearer sk_test_VOTRE_CLE" \
  -H "Content-Type: application/json" \
  -d '{"amount":1500,"method":"natcash","reference":"CMD-4822"}'

Comment commencer

  1. Créez un compte et confirmez votre email avec le code reçu.
  2. Créez une clé de test sk_test_... dans le tableau de bord (section Clés API).
  3. Créez un premier paiement dans le mode test, sans argent réel.
  4. Enregistrez votre URL de webhook pour recevoir les confirmations.
  5. Passez en production : les mêmes appels fonctionnent avec une clé sk_live_....

Vous n'écrivez pas de code ? Utilisez un lien de paiement, le bouton de paiement à copier-coller, ou le plugin WordPress et WooCommerce.

Questions fréquentes sur l'API MonCash et Natcash

Comment tester l'API sans argent réel ?

Chaque compte dispose d'un mode test avec des clés sk_test_... et d'un solde de démonstration. Vous pouvez créer des paiements de test et vérifier votre intégration avant de passer en production.

Comment savoir qu'un paiement MonCash ou Natcash a réussi ?

Enregistrez une URL de webhook : vous recevez un événement signé payment.succeeded. Vous pouvez aussi interroger l'API avec l'identifiant du paiement. Vérifiez toujours la signature du webhook avant de livrer une commande.

Puis-je envoyer de l'argent vers MonCash et Natcash ?

Oui, avec l'API de retrait (POST /v1/payouts), depuis votre solde Gateway. Le statut se suit par webhook (payout.succeeded, payout.failed) ou par vérification.

Dans quels langages puis-je l'intégrer ?

L'API est une API REST en JSON, utilisable avec tout langage. Nous fournissons des SDK pour Node.js et PHP, une spécification OpenAPI, et des plugins pour WordPress et WooCommerce.

Puis-je aussi accepter les cartes Visa et Mastercard ?

Oui. Le paiement par carte est disponible : Visa et Mastercard en USD, avec Amazon Pay, Cash App et Link selon le pays du client. Frais : 7 % + 0,50 $ (Standard), 6 % + 0,50 $ (Pro), 5 % + 0,50 $ (Business). Testez en mode Sandbox avec la carte 4242 4242 4242 4242, date 05/27, CVV 088. Vous pouvez aussi émettre vos propres cartes virtuelles depuis le même compte. Voir les cartes virtuelles.
