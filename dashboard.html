Démarrage rapide
Copiez ces extraits pour utiliser le Gateway et l'Issuing dans votre environnement sandbox. Installation : npm install @fredapay/issuing.
// Accepter un paiement (MonCash / Natcash)
const { FredaPay } = require("@fredapay/issuing");
const freda = new FredaPay(process.env.FREDA_SECRET_KEY); // sk_test_...
const payment = await freda.payments.create({
  amount: 1500,
  method: "moncash",
  reference: "CMD-1001"
});
// redirigez votre client vers payment.checkout_url// Émettre une carte virtuelle (titulaire, puis carte)
const created = await freda.cards.holders.create({
  firstName: "Jane", lastName: "Doe", email: "jane@example.com",
  country: "US", dob: "1990-05-12", identificationNumber: "ID123456",
  identity: { type: "PASSPORT", number: "P1234567", imageUrl: "data:image/jpeg;base64,/9j/4AAQ..." },
  phoneShortCode: "+1", phoneNumber: "2025550123",
  address: { street: "350 Fifth Avenue", city: "New York", state: "NY", postalCode: "10118", country: "US" }
});
const card = await freda.cards.create({
  reference: "CARD-001", kind: "individual", brand: "VISA",
  amount: 20, holder_id: created.holder.id
});
// la carte passe à "active" quelques secondes plus tard (freda.cards.get)// Envoyer de l'argent (MonCash / Natcash)
const payout = await freda.payouts.create({
  amount: 500,
  method: "natcash",
  recipient: "50937001234",
  reference: "PO-1001"
});
Environnement Sandbox
Ce que vous devez savoir pour tester sans engager de vrais fonds.
  • Vos soldes Sandbox sont fictifs (5 000 $ de bienvenue sur le Master Wallet). Ils n'ont aucun lien avec vos soldes Live.
  • Les cartes Sandbox sont créées sur notre environnement de test. Ouvrez une carte puis utilisez « Simuler un achat » ou « Simuler un crédit » pour générer des transactions.
  • Une clé sk_test_ ne voit que les données Sandbox, et une clé sk_live_ que les données Live.
  • Rien du Sandbox n'est repris en Live : titulaires, cartes, plan, soldes et clés repartent de zéro.
